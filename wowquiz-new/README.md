# WOWQUIZ Booking Processor

## Описание
Автоматизация обработки писем с заявками и запись данных в Google Sheets.

## Быстрый старт

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните свои значения.

3. Запустите:
   ```
   python src/main.py
   ```

## Тесты

```
pytest
```

## Безопасность

- Не храните .env в публичном доступе!
- Ключи Google API — только для сервисных аккаунтов.

## Состав проекта
- src/ — исходный код
- tests/ — тесты
